## 4.1 样本概况与随机化平衡检验 (Sample Overview & Randomization Balance)

本研究所依赖的实证数据源自 Edgewise 在线求职实训系统部署的 $2 \times 2$ 完全因子化田野随机对照实验（Field Randomized Controlled Trial）。共有 $N = 400$ 名完整完成前测、产品核心任务、即时反馈及 7 日跟踪回访的受试者纳入最终分析样本。每个实验组严格分配 100 名受试者：
- **Arm 00** ($n = 100$): 断续入口触点（$Z_C = 0$） + 被动示范观察（$Z_P = 0$）
- **Arm 01** ($n = 100$): 断续入口触点（$Z_C = 0$） + 主动构念演练（$Z_P = 1$）
- **Arm 10** ($n = 100$): 连续入口触点（$Z_C = 1$） + 被动示范观察（$Z_P = 0$）
- **Arm 11** ($n = 100$): 连续入口触点（$Z_C = 1$） + 主动构念演练（$Z_P = 1$）

为确保实验操纵的因果推断有效性，首先对四组受试者的基线人口统计学特征、求职紧迫度、核心痛点、AI 工具使用经验及先验求职能力进行了随机化平衡检验（Randomization Balance Test）。如表 1 所示，各组在求职阶段分布（$\chi^2(9) = 6.99, p = .638$）、面试核心痛点（$\chi^2(9) = 7.72, p = .563$）、AI 经验（$\chi^2(6) = 8.33, p = .215$）、目标岗位（$\chi^2(3) = 0.00, p = 1.000$）及渠道构成（$\chi^2(12) = 0.00, p = 1.000$）上均无统计学显著差异。单因素方差分析（One-way ANOVA）显示，先验求职能力在四组间高度平衡（$F(3, 396) = 0.65, p = .585$），日均备考时长亦无组间偏倚（$F(3, 396) = 2.38, p = .069$），证明随机分组程序彻底消除了样本选择偏误。

## 4.2 测量模型与构念信效度分析 (Measurement Model & Construct Reliability)

依据心理测量学及信息系统顶刊通行准则，对本研究采用的 8 个潜变量构念进行了信度（Reliability）、聚合效度（Convergent Validity）及区分效度（Discriminant Validity）检验。

### 4.2.1 量表信度与题项诊断
对于包含 3 个及以上题项的潜变量（先验能力、触点连续性、信息诊断性、反馈质量、学习掌控感、过程信任），计算标准化克隆巴赫系数（Cronbach's $\alpha$）；对于 2 题项构念（智能体相关性、预期契合度），计算斯皮尔曼-布朗折半校正信度系数（Spearman-Brown $\rho_{sb}$）。题项净化检验涵盖校正题项-总分相关度（Corrected Item-Total Correlation, CITC）与删除题项后信度（Alpha-if-Item-Deleted）。
如表 3 所示，所有量表的信度系数均在 $0.900$ 至 $0.979$ 之间，大幅超出 $0.70$ 的经典学术门槛；所有题项的 CITC 均高于 $0.79$（远高于 $0.30$ 准则），且删除任意单项均未能进一步提高全量表 $\alpha$ 值，表明量表题项具备高度同质性与测量稳定性。

## 4.3 实验操纵检验 (Manipulation Checks)

为确认自变量 $Z_C$（触点连续性）与 $Z_P$（主动演练）被受试者精准感知，执行了正式的实验操纵检验：
1. **连续触点操纵 ($Z_C$)**：通过题项 C1（“进入产品后，我不需要重新选择功能，就能直接练习之前关心的那个问题”，1-7 点量表）及系统记录的真实对齐率（`zc_realized`）进行检验。
2. **主动演练操纵 ($Z_P$)**：通过题项 F1（受试者对作答模式的客观确认：“自己作答再修改” vs “观看理想答案示范”）进行检验。

表 5 的检验结果表明，$Z_C = 1$ 实验组的连续性得分显著高于 $Z_C = 0$ 组（$\mu_{1} = 5.91$ vs $\mu_{0} = 2.29$，均值差 $+3.62, t = 55.65, p < .001$，Cohen's $d = 5.56$）；$Z_C = 1$ 组达标率达 98.5\%，系统真实题目对齐率达 97.5\%。对于 $Z_P$ 操纵，$Z_P = 1$ 组报告“自己作答再修改”的比例为 100.0\%，而 $Z_P = 0$ 组报告“示范观察”的比例为 100.0\%（$\chi^2(1) = 396.01, p < .001$）。两项操纵检验均告完全成功。

## 4.4 假设检验与实证结果 (Hypothesis Testing & Empirical Findings)

### 4.4.1 命题 1 检验：触点连续性效应 (Proposition 1: Touchpoint Continuity Effect)

**命题 1 (P1)** 提出：外部触点与产品内演练场景的连续对齐（$Z_C = 1$）能显著降低用户的认知重建成本，缩短首次作答启动耗时，并减少界面重选步数。

为检验 P1，建立普通最小二乘法（OLS）回归模型：
$$\text{RebuildCost}_i = \beta_0 + \beta_1 Z_{C,i} + \beta_2 \text{PriorAbility}_i + \varepsilon_i$$

回归结果详见表 6。在控制先验能力后，触点连续性（$Z_C$）对首次作答耗时呈现极显著的负向削减作用（$\hat{\beta} = -131.41, t = -74.60, p < .001, R^2 = 0.933$），即连续对齐使首次答题启动时间由断续组的平均 173.5 秒骤降至 42.1 秒，净节省 131.4 秒；步数显著减少 4.68 步（$t = -60.07, p < .001, R^2 = 0.901$）；入口重选次数减少 2.27 次（$t = -39.82, p < .001, R^2 = 0.800$）。受试者主观触点连续性感知得分显著提高 3.32 分（$t = 49.28, p < .001, R^2 = 0.859$）。**命题 1 获得极为充分的经验证据支持**。

### 4.4.2 命题 2 检验：主动构念演练效应 (Proposition 2: Active Practice Effect)

**命题 2 (P2)** 提出：相比被动观察理想答案示范，引导受试者开展主动构念表达与追问修改（$Z_P = 1$）能显著提升其技能习得掌控感、反馈诊断质量评价，并促成更高质量的 7 日迁移测试（Transfer Test）成绩。

实证回归方程构建如下：
$$\text{Outcome}_i = \alpha_0 + \alpha_1 Z_{P,i} + \alpha_2 Z_{C,i} + \alpha_3 \text{PriorAbility}_i + \boldsymbol{\gamma}' \mathbf{Controls}_i + \varepsilon_i$$

### 4.4.3 命题 3 检验：超加性互补效应 (Proposition 3: Superadditive Complementarity ΔCP)

**命题 3 (P3 - 本书核心理论命题)** 提出：触点连续性（$Z_C$）与主动构念演练（$Z_P$）在驱动长期合格激活行为（Qualified Activation）上存在超加性互补关系（Superadditive Complementarity）。即双要素联合实施的净增益严格大于两项要素单独实施时的增益之和：
$$\Delta_{CP} = \mu_{11} - \mu_{10} - \mu_{01} + \mu_{00} > 0$$

表 8 报告了合格激活率的 $2 \times 2$ 单元格均值及边际增量。在断续触点下（$Z_C = 0$），将示范转为演练使激活率从 12.0\% 上升到 35.0\%（净增 +23.0\%）；在被动示范下（$Z_P = 0$），引入触点连续性使激活率从 12.0\% 上升到 30.0\%（净增 +18.0\%）。若两要素仅具线性独立效应，联合实施的预期激活率应为 12.0\% + 23.0\% + 18.0\% = 53.0\%。然而，Arm 11 实际测得的合格激活率高达 **78.0\%**，产生了额外高达 +25.0\% 的超额协同溢价。

### 4.4.6 命题 6 检验：激励结构与过程信任对裂变传播的影响 (Proposition 6: Viral Incentives & Trust)

3. **极端值与截断敏感度分析**：
