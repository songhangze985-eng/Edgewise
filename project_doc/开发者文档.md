## 一、项目概述

### 1.1 产品简介

谈锋 Edgewise 是一款 AI 驱动的面试训练平台，核心目标是帮助求职者系统性提升面试能力。平台提供三大核心功能模块：

1. **LGD 无领导小组讨论模拟** -- 7 个性格各异的 AI 角色 + 1 个真人用户组成 8 人圆桌讨论，市面唯一的群面模拟产品
2. **1v1 模拟面试** -- 支持结构化、半结构化、行为面试三种模式，含温和/中立/高压三级难度
3. **简历 AI 优化** -- 上传简历自动解析、STAR 法则重构、JD 精准匹配、流式输出优化结果

辅助功能包括：面试题库（STAR 法则引导）、深度复盘中心（五维评估 + 逐字稿批改 + 满分话术重构）、一血通关挑战（Permadeath 模式）、定制工坊（沙盒自定义面试场景）、管理后台（用户/题库/系统管理）。

## 二、快速启动

### 2.1 环境要求

| 工具 | 最低版本 | 说明 |
|:---|:---|:---|
| Node.js | 18+ | 推荐 20 LTS |
| npm | 9+ | 随 Node.js 安装 |
| Python | 3.12+ | 后端运行时 |
| Redis | 6+ | 数据存储 |

### 2.2 前端启动

```bash
# 进入项目根目录
cd Edgewise

# 安装依赖
npm install

# 启动开发服务器 (默认端口 3000，自动打开浏览器)
npm run dev
```

开发服务器地址: `http://localhost:3000`

### 2.3 后端启动

```bash
# 进入后端目录
cd backend

# 创建虚拟环境 (推荐)
python -m venv .venv
source .venv/bin/activate  # macOS/Linux

# 安装依赖
pip install -r requirements.txt

# 启动开发服务器 (热重载)
python run.py
```

后端 API 地址: `http://localhost:8000`
API 文档地址: `http://localhost:8000/docs` (Swagger UI)

### 2.4 Redis

```bash
# macOS (Homebrew)
brew install redis
brew services start redis

# 验证连接
redis-cli ping
# 预期输出: PONG
```

默认连接地址: `redis://localhost:6379/0`

### 2.5 环境变量

后端支持通过 `.env` 文件配置环境变量 (放在 `backend/` 目录下):

```env
REDIS_URL=redis://localhost:6379/0
JWT_SECRET=your-production-secret-key
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=1440
CORS_ORIGINS=["http://localhost:3000","http://localhost:5173"]
```

#### 3.5.2 ThreeBackground

使用 `@react-three/fiber` 渲染的全屏 3D 线框背景，包含以下几何体:

- `WireframeCube`: 旋转的线框立方体 (两个，不同大小和透明度)
- `WireframeOctahedron`: 旋转的线框八面体 (紫色)
- `ConcentricCircles`: 同心圆环组 (倾斜旋转)
- `HelixWave`: 螺旋波形线 (红色 + 蓝色，相位偏移 PI)

配置: `orthographic` 正交相机，`zoom=40`，`antialias=true`，`alpha=true`。

#### 3.5.3 AICopilot

集成 `page-agent` SDK 的 AI 页面操控助手。

- **按钮**: 固定在右下角的圆形按钮，运行中显示动画图标
- **面板**: 包含页面上下文感知的快捷指令、消息流、文本输入
- **引擎**: 使用 `PageAgent` 类，模型 `qwen3.5-plus`，自动分析 DOM 并执行用户指令
- **页面感知**: 根据当前路由自动切换快捷建议 (Dashboard / LGD Lobby / LGD Room / Resume)

#### 3.5.4 SettingsModal

ChatGPT 风格的设置弹窗，通过 `createPortal` 挂载到 `document.body`。

5 个设置标签页:

| 标签页 | 功能 |

| 常规 | 外观主题 (深色/浅色/跟随系统)、语言、AI Copilot 开关、音效 |
| 账户 | 用户名、邮箱、加入时间、修改密码 |
| 订阅 | 当前等级、积分、管理订阅 |
| 偏好设置 | 每日练习提醒、邮件通知 |
| 数据管理 | 导出数据、清除缓存、删除账户 |

### 4.5 认证流程

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 注册                                                        │
│  POST /api/v1/auth/register                                     │
│  Body: { email, password, name }                                │
│  -> 密码 bcrypt 哈希 -> 存入 Redis -> 返回 UserPublic           │
│  -> 首个用户自动 is_admin=true                                  │
└─────────────────────────────────────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────────┐
│  2. 登录                                                        │
│  POST /api/v1/auth/login                                        │
│  Body: { email, password }                                      │
│  -> 验证密码 -> 签发 JWT Token (HS256, 24h 有效期)              │
│  -> 返回 { access_token, token_type, expires_in, user }         │
└─────────────────────────────────────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────────┐
│  3. 认证请求                                                    │
│  Header: Authorization: Bearer <token>                          │
│  -> 解码 JWT -> 检查 token:blacklist:{jti} -> 加载用户          │
│  -> 注入 current_user 到路由处理器                              │
└─────────────────────────────────────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────────┐
│  4. 登出                                                        │
│  POST /api/v1/auth/logout                                       │
│  -> Token JTI 加入黑名单 (TTL = 剩余有效期)                    │
│  -> 后续请求带此 Token 将被拒绝                                 │
└─────────────────────────────────────────────────────────────────┘
```

**JWT Token Payload**:

```json
{
  "sub": "user-id",
  "email": "user@example.com",
  "is_admin": false,
  "type": "access",
  "jti": "unique-token-id",
  "iat": 1710000000,
  "exp": 1710086400
}
```

## 六、数据流

### 6.1 认证流程

```
Login 页面
  │
  ├─ 输入邮箱密码 -> handleSubmit()
  │   └─ authStore.login(email, name)
  │       ├─ 生成 user 对象 (id, email, name, initials, tier, credits, joinDate)
  │       ├─ 设置 isAuthenticated = true
  │       └─ 自动持久化到 localStorage (key: edgewise-auth)
  │
  ├─ SSO 快捷登录 -> handleSocialLogin(provider)
  │   └─ authStore.login('{provider}@edgewise.ai', '{provider} 用户')
  │
  └─ navigate('/')
       └─ ProtectedRoute 检查 isAuthenticated -> 通过 -> 渲染 Layout
```

### 6.2 练习会话流程

```
LGDRoom / InterviewRoom
  │
  ├─ 练习过程中维护各自 store (lgdStore / 组件内部状态)
  │
  └─ 练习结束时
      └─ sessionStore.addSession({
           type: 'lgd' | 'interview',
           topic: '...',
           score: 85,
           durationMinutes: 45,
           dimensions: { expression, logic, leadership, teamwork, adaptability }
         })
         ├─ 生成唯一 ID (s-{timestamp})
         ├─ 追加到 sessions 数组 (最多 50 条)
         ├─ 重新计算 stats (totalSessions, totalDuration, avgScore, streak)
         └─ 自动持久化到 localStorage (key: edgewise-sessions)

Dashboard / Analytics / Profile
  └─ 从 sessionStore 读取数据展示
```

### 6.3 退出登录流程

```
Sidebar 用户菜单 -> 点击「退出登录」
  │
  ├─ authStore.logout()
  │   ├─ user = null
  │   ├─ isAuthenticated = false
  │   └─ localStorage 更新 (edgewise-auth)
  │
  └─ navigate('/login')
      └─ ProtectedRoute 检测 isAuthenticated=false -> Navigate to /login
```

### 6.4 简历优化流程

```
Resume 页面
  │
  ├─ 上传文件 -> resumeStore.setFile(file)
  │   └─ 模拟上传进度 (0-100%)
  │
  ├─ resumeStore.startParsing()
  │   └─ 2 秒后 resumeStore.setParsedData(null) -> 使用 Mock 数据
  │
  ├─ JD 匹配 -> resumeStore.setJdText(text) -> resumeStore.analyzeJdMatch()
  │   └─ 关键词匹配 + 计算分数
  │
  └─ 开始优化 -> resumeStore.startOptimizing()
      └─ 逐字追加 (30ms/字) -> resumeStore.appendOptimizedChar(char)
      └─ 完成 -> resumeStore.setOptimizedText(fullText)
```

|:---|:---|

| 文件名 | PascalCase.jsx (组件) / camelCase.js (工具) |
| CSS 文件名 | ComponentName.module.css |
| CSS 类名 | kebab-case (CSS Modules 自动作用域) |
| 常量 | UPPER_SNAKE_CASE |

## 九、已知技术债务

### 9.1 前端

- [ ] **所有数据为 Mock/localStorage** -- 前端 store 直接使用 Mock 数据和 localStorage 持久化，未接入真实后端 API
- [ ] **authStore 无真实认证** -- 登录仅在前端设置状态，不发送 API 请求，不存储 JWT Token
- [ ] **LGD 无 WebSocket 实现** -- 群面讨论使用前端定时器模拟 AI 发言，未实现真正的实时通信
- [ ] **简历解析使用 Mock 数据** -- `resumeStore.setParsedData(null)` 直接使用预设的 Mock 简历数据
- [ ] **JD 匹配使用关键词匹配** -- 非真实的语义匹配，仅检查 JD 文本中是否包含预定义关键词
- [ ] **无文件上传到对象存储** -- 简历文件仅在前端内存中，未上传到 OSS/S3
- [ ] **无真实 LLM 集成** -- 面试官回复和简历优化均为预置文本，非 AI 生成
- [ ] **ThreeBackground 性能问题** -- 全屏 3D 线框动画在低端设备上可能造成性能瓶颈，无降级策略
- [ ] **copilotStore 基于关键词匹配** -- AI Copilot 对话使用硬编码的关键词规则，非真实 NLP
- [ ] **AICopilot (PageAgent) 依赖外部服务** -- page-agent SDK 连接的 baseURL 为阿里云函数计算地址，可能不稳定
- [ ] **无国际化 (i18n) 支持** -- 所有 UI 文本硬编码为中文
- [ ] **SettingsModal 设置不持久化** -- 外观主题、语言、通知等偏好设置仅存在于组件状态，刷新后重置

### 9.2 后端

- [ ] **Redis 作为唯一数据库** -- 生产环境应使用 PostgreSQL/MySQL 持久化核心数据
- [ ] **简历解析为基础文本提取** -- 仅提取邮箱、电话、教育、技能关键词，无真实 NLP/OCR 解析
- [ ] **无 WebSocket 端点** -- LGD 实时通信需要添加 WebSocket 支持
- [ ] **无速率限制** -- API 端点无请求频率限制
- [ ] **无文件存储服务** -- 简历文件以 base64 存储在 Redis 中，大文件会占用大量内存
- [ ] **JWT Secret 硬编码** -- 默认密钥 `edgewise-secret-key-change-in-production` 需要在生产环境替换
- [ ] **无日志系统** -- 缺少结构化日志记录
- [ ] **无单元测试** -- 后端无测试覆盖
