## 二、市场背景与痛点分析

### 2.1 行业现状

- 2025 届全国高校毕业生规模预计再创新高，就业竞争持续加剧。
- 求职者普遍缺乏高质量的面试模拟手段，尤其是**无领导小组讨论 (LGD)** 几乎无从练起。
- 传统的"刷面经 + 对镜练习"模式缺乏即时反馈和压力模拟，训练效果难以量化。

### 2.2 核心痛点

| 痛点 | 现有解决方案不足 |
|------|------------------|
| **无对手可练** | 真人模拟面试成本高、难组织，AI 单面产品已有但水平参差 |
| **群面完全空白** | 市面上几乎没有能模拟 LGD 多角色动态博弈的产品 |
| **反馈不专业** | 录像回放只能"自己看"，缺乏结构化的多维评估和话术重构 |
| **训练无动力** | 缺少游戏化激励机制，用户难以坚持足够时长的练习 |

## 四、核心功能模块设计

整体 Web App 划分为 **六大核心工作舱**，采用"克莱因蓝 + 深色科技风 (Dark Mode)"的 UI 视觉，缓解长时间练习的视觉疲劳。

### 模块一：智启工作台 (Dashboard & Onboarding)

用户的总指挥部与数据中心。

- **多端便捷登录**：支持微信扫码、邮箱注册以及 Google 一键授权登录。
- **极速备战 - 简历解析与 AI 优化**：首页核心组件"拖拽上传简历 / JD"。AI 秒级解析提取关键经历，同时提供**智能简历优化建议**（表达润色、量化成果强化、关键词匹配 JD），并一键生成针对性的定制化面试房间。
- **全景能力雷达图**：动态展示用户在逻辑表达、专业深度、情绪管理、团队协作、领导力五维度的量化得分。
- **职场征途看板**：展示用户经验值 (EXP)、段位等级（从"青铜实习生"到"王者谈锋"）以及可用积分余额。
- **AI Copilot 智能引导 (PageAgent 驱动)**：首次登录或进入新功能区时，页面内嵌 AI Copilot 自动识别当前界面，用自然语言引导用户完成关键操作（如"帮我上传简历并创建面试房间"）。降低学习成本，提升新手转化率。

### 模块二：全息面试引擎 (Immersive Interview Arena)

产品的绝对核心模块，充分利用 PC 大屏提供渐进式的真实高压模拟。

#### 2.1 结构化 / 半结构化单面 (1v1 Interview)

- **动态沉浸 UI**：左侧 AI 面试官动态声纹/虚拟人像，右侧实时语音转文本 (STT) 流水及思考倒计时，支持长按空格键开麦。
- **高压追问机制 (Dynamic Probing)**：打破固定题库。当用户回答出现逻辑断层或不符合 STAR 法则时，AI 考官敏锐打断并施加追问压力。
- **环境光效渲染**：Web 界面边缘根据面试压力等级（温和 / 中立 / 高压）呈现不同氛围光效。

#### 2.2 无领导小组讨论 (LGD) - 独家杀手锏

- **大屏虚拟圆桌 UI**：完美利用 Web 宽屏，呈现 8 人圆桌界面（1 名真人 + 7 个差异化人设 AI 智能体，如：破冰者、计时员、点子王、杠精）。
- **多角色动态博弈**：AI 之间互相赞同或驳斥，真实用户需找准时机点击"抢麦"或语音打断介入。
- **全真流程控场**：5 分钟独立阅卷白板 -> 轮流发言 -> 自由激辩 -> 投票推选总结者。后台 Coordinator Agent 全局控场，防止话题严重跑偏。

### 模块三：极客竞技场 (Gamified Arena)

引入电子竞技的"爽感"机制，打破枯燥练习的留存瓶颈。

- **"一血通关"极限挑战 (Permadeath Challenge)**
  - 模拟大厂真实连轴面试流程：群面 -> 业务主管单面 -> 交叉压测 -> HR 终面。
  - 采用"血条"机制，任意一轮评分低于安全线即 Game Over；一命通关者触发全站特效广播，并生成专属战报长图供社交分享裂变。
- **多人实时匹配 (Live PVP Matchmaking)**
  - 匹配 2-4 名真实用户同场作答，AI 担任主考官，系统实时出分走势图，打造"求职版排位赛"。

### 模块四：沙盒定制工坊 (Creative Studio)

面向高级用户的高自由度自定义工具。

- **考官"捏脸"系统**：自定义面试官严厉程度、语速、口音偏好及提问风格。
- **AIGC 场景渲染**：用户输入提示词（如"充满未来感的透明高管办公室"），大模型秒级生成专属沉浸式 Web 背景图。
- **突发事件注入**：模拟真实意外（"网络卡顿要求重复"、"考官突然接电话"、"专业名词刁难"），极致考验应变力。

### 模块五：深度复盘与评估中心 (Deep Analytics)

利用网页大屏优势，提供高密度专业图文报告。

- **双轨评估报告**：后台双评估 Agent 分别从"硬技能（专业知识）"和"软素质（角色契合度 / 沟通力）"双向打分。
- **逐字稿智能批改**：完整录音回放，系统自动将口癖（"嗯"、"那个"等）和逻辑漏洞标红。
- **满分话术重构 (Golden Answer)**：AI 保留用户原生经历，运用 STAR 法则重构出一份"建议高分回答"，支持并排对比学习。

### 模块六：谈锋道场社区 (Community Dojo)

- **面经录像广场**：用户可将高分答卷（自动声音和隐私脱敏处理）发布至社区，供他人观摩学习。
- **大厂真题悬赏池**：遇到奇葩真题可发布悬赏，利用社区智慧 + AI 共同拆解高分答题框架。

## 五、竞品分析与差异化优势

| 维度 | 传统面试辅导平台 | 已有 AI 面试产品 | **谈锋 Edgewise** |
|------|------------------|------------------|---------------------|
| **面试模式** | 真人一对一（高成本） | AI 1v1 单面 | AI 1v1 单面 + **LGD 群面（独家）** |
| **压力模拟** | 依赖面试官水平 | 简单追问 | 高压追问 + 环境光效 + 突发事件注入 |
| **评估维度** | 主观点评 | 单维打分 | 双轨评估 + 逐字稿批改 + STAR 话术重构 |
| **用户粘性** | 低（一次性服务） | 中 | 高（段位/血条/排位赛/社区裂变） |
| **B 端能力** | 无 | 少量 | 企业 HR 初筛 SaaS 全流程覆盖 |

**核心壁垒**：能让 7 个差异化 AI 智能体与 1 个真人进行逻辑自洽的圆桌讨论，这在当前市场上近乎空白。

## 六、商业化变现模型

采用 **"SaaS 阶梯订阅 + 积分 Token 消耗"** 的混合漏斗模式：

| 会员等级 | 适用人群 | 核心权益 |

| **Enterprise (企业版)** | 中小企业 HR / 猎头 | 独立 B 端管理后台，批量 AI 初筛 + 候选人胜任力排名看板 |

### 7.3 PageAgent 智能引导层

集成阿里巴巴开源项目 [page-agent](https://github.com/alibaba/page-agent)（MIT 协议），为 Edgewise 增加**页面内 AI Copilot** 能力。

#### 选型理由

| 优势 | 说明 |
|------|------|
| **纯前端集成** | 无需浏览器插件、Python 后端或无头浏览器，一行 JS 即可嵌入 |
| **文本 DOM 操作** | 基于 DOM 文本理解而非截图，无需多模态视觉模型，成本更低 |
| **自带 UI** | 内置美观的交互界面和 human-in-the-loop 确认机制 |
| **BYO LLM** | 支持接入任意 OpenAI 兼容模型（通义千问 / DeepSeek / GPT 等），与 Edgewise 现有大模型统一 |

#### 接入方式

```bash
npm install page-agent
```

```javascript
import { PageAgent } from 'page-agent';

const copilot = new PageAgent({
  model: 'qwen3.5-plus',
  baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1',
  apiKey: process.env.LLM_API_KEY,
  language: 'zh-CN',
  instructions: {
    system: '你是谈锋 Edgewise 的智能引导助手，帮助用户快速上手面试训练平台。',
    page: '当前页面是 Edgewise 面试训练平台。'
  }
});

// 示例：引导用户上传简历并创建面试房间
await copilot.execute('帮用户找到简历上传区域，高亮显示并提示拖拽上传');
```

#### 在 Edgewise 中的应用场景

| 场景 | 自然语言指令示例 | 模块 |

## 九、功能优先级与开发路线

### 9.1 优先级分层

> **核心原则**：惊艳功能优先。先把能形成差异化壁垒 + 展示效果拉满的功能做透，再补齐基础能力。

#### P0 - 首发必做（MVP 核心四件套）

| 功能 | 所属模块 | 理由 |
|------|----------|------|
| **产品面板 (Dashboard)** | 模块一 | 产品门面与用户总指挥部，登录 + 导航 + 数据总览，第一印象决定留存 |
| **LGD 无领导小组讨论（群面）** | 模块二 | **唯一杀手锏** - 7 个 AI + 1 个真人圆桌讨论，市面近乎空白，比赛拿分和传播的绝对核心 |
| **简历 AI 优化** | 模块一 | 上传简历后 AI 解析 + 智能优化建议（表达润色、量化成果、关键词匹配 JD），高频刚需且即见价值 |
| **PageAgent 智能引导** | 模块一 | 纯前端一行集成，用户用自然语言操控界面，极大增强科技感与路演展示效果 |

#### P1 - 重要但可延后（MVP 验证后优先迭代）

| 功能 | 所属模块 | 理由 |
|------|----------|------|
| 1v1 结构化/半结构化单面 | 模块二 | 面试训练基本盘，但市面竞品多，非差异化点，可紧跟群面后连续交付 |
| 基础复盘报告（逐字稿 + 打分） | 模块五 | 反馈很重要，但可在群面打通后快速补上 |
| 高压追问机制 (Dynamic Probing) | 模块二 | 1v1 体验差异化，初期可先用固定题库 |
| 满分话术重构 (Golden Answer) | 模块五 | STAR 法则重构是强需求，但可第二期做 |
| 双轨评估报告 | 模块五 | 初期可以只做单维评估 |
| 全景能力雷达图 | 模块一 | 体验加分项，核心价值在面试模拟本身 |
| 段位 / EXP 经验值系统 | 模块一 | 留存机制重要，但先验证产品核心价值 |

#### P2 - 锦上添花（产品验证成功后再做）

| 功能 | 所属模块 | 理由 |
|------|----------|------|
| "一血通关"极限挑战 | 模块三 | 游戏化好玩但复杂度高，需串联多轮面试 + 血条系统 |
| 多人实时 PVP 匹配 | 模块三 | 需要在线用户规模达到一定量级才有意义 |
| 沙盒定制工坊（捏脸/场景渲染/突发事件） | 模块四 | 高级玩法，面向付费用户，MVP 阶段价值低 |
| 环境光效渲染 | 模块二 | 视觉体验加分，不影响核心功能 |
| AIGC 背景图生成 | 模块四 | 酷但非必需 |

#### P3 - 可砍掉或大幅简化

| 功能 | 所属模块 | 理由 |
|------|----------|------|
| Enterprise 企业版 B 端 | - | 完全不同的产品线，需要独立管理后台/权限/数据隔离，**不在 C 端 MVP 阶段碰** |
| 面经录像广场 / 社区 | 模块六 | 需要足够多用户产出内容才能运转 |
| 大厂真题悬赏池 | 模块六 | UGC 机制依赖社区活跃度 |
| 复杂积分代币经济系统 | - | 初期直接做免费/付费两档，复杂积分体系等验证 PMF 后再建 |

### 9.2 分期开发计划

```
第 1 期 - MVP 核心四件套 (4-6 周)                       <- P0 全部
  |-- 产品面板 Dashboard（登录 + 导航 + 数据总览）
  |-- LGD 无领导小组讨论（核心中的核心）
  |-- 简历 AI 优化（上传解析 + 智能润色/量化强化/JD 匹配）

第 2 期 - 基础能力补齐 + 内测 (3-4 周)                  <- P1
  |-- 1v1 结构化/半结构化单面（含 STT + AI 考官）
  |-- 基础复盘报告 + 话术重构
  |-- 能力雷达图 + 段位/EXP 系统
  +-- 校园内测 50-100 人，收集反馈迭代

第 3 期 - 增长扩展 (按需)                                <- P2 择优
  |-- 一血通关 / PVP 排位赛
  |-- 沙盒定制工坊
  +-- 社区 & 企业版（视 PMF 验证结果决定）
```

## 十、UX 设计策略

### 10.1 视觉欺骗 - 掩盖 AI 延迟

大模型多 Agent 推理时不可避免存在 1-3 秒延迟。前端需通过以下手段让交互感知丝滑自然：

- 当轮到 AI 发言时，先显示头像"正在整理思绪..."动画
- 播放 1 秒预设音频（如"嗯，我认为..."、清嗓子声）
- 使用打字机效果逐字输出文本，而非整段闪现

### 10.2 渐进式体验引导

- 首次使用引导用户完成一次简短的 1v1 单面试炼，建立信心后再推荐 LGD 群面
- 通过段位系统和每日任务维持用户长期活跃度

## 十一、风险识别与应对

| 风险 | 等级 | 应对策略 |
|------|------|----------|
| LGD 多 Agent 对话逻辑串线 | 高 | Coordinator Agent 全局控场 + 每轮发言前上下文校验 |
| 大模型响应延迟影响体验 | 中 | 视觉欺骗策略 + 流式输出 + 预生成开场白缓存 |
| 用户冷启动留存低 | 中 | 免费层每日积分 + 新手引导 + 段位激励体系 |
| 音视频跨浏览器兼容问题 | 中 | WebRTC 兼容性测试矩阵 + 降级方案（纯文本/语音） |
| 用户隐私与内容安全 | 中 | 录音录像自动脱敏 + 社区内容审核机制 + 合规审计 |
